# Plugin documentation

Documentation for the plugins maintained in this fork. Each plugin has four
documents, following the [Divio documentation system](https://docs.divio.com/documentation-system/):

| Type | Purpose | Read it when you want to |
| --- | --- | --- |
| Tutorial | A guided first run that ends in a working result | learn the plugin by using it |
| How-to guides | Steps for one specific task | get a job done |
| Reference | Settings, files, commands and hooks, described exactly | look something up |
| Explanation | Design, behavior and limits, and why | understand the plugin |

| Plugin | Tutorial | How-to guides | Reference | Explanation |
| --- | --- | --- | --- | --- |
| `os-bind-rp` | [tutorial](bind/tutorial.md) | [how-to](bind/how-to.md) | [reference](bind/reference.md) | [explanation](bind/explanation.md) |
| `os-ha-dhcp-interface` | [tutorial](ha-dhcp-interface/tutorial.md) | [how-to](ha-dhcp-interface/how-to.md) | [reference](ha-dhcp-interface/reference.md) | [explanation](ha-dhcp-interface/explanation.md) |

Both plugins install from the signed Resolver Plugins repository; see the
[root README](../../README.md) to configure it and the
[maintainer reference](../maintainers/reference.md) for feeds, Releases and
series upgrades.

Keep each document to its type. A tutorial does not list every option, a
how-to guide does not explain design, a reference does not give instructions
and an explanation does not walk through steps; link to the other document
instead.
